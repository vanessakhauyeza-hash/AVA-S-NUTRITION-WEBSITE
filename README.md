# Ava's Nutrition Hub

A free, responsive nutrition education website created as a portfolio project.

## Project purpose

The project combines a background in Food Security & Nutrition with Computer Science to explore how digital tools can make practical nutrition information easier to access.

## Current features

- Responsive homepage
- Nutrition basics
- Local-food balanced-plate examples
- Educational energy-needs calculator
- Digital-health project section
- Mobile navigation
- Accessible semantic HTML
- No backend required

## Files

- `index.html` — website structure and content
- `style.css` — responsive styling
- `script.js` — navigation and calculator functionality

## Important

The calculator is educational and is not intended to replace personalised advice from a qualified health professional.
